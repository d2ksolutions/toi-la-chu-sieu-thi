# Tôi Là Chủ Siêu Thị — bản web 0.3.0

Game quản lý siêu thị 3D: xây kệ, nhập hàng, đặt giá, thuê nhân viên, đón khách và phát triển cửa hàng qua 6 cấp.

**Chơi ngay:** https://d2ksolutions.github.io/toi-la-chu-sieu-thi/

- Chơi trên máy tính với Chrome hoặc Edge bản mới (cần WebGL2); điện thoại chưa hỗ trợ.
- Không cần tài khoản. Bản lưu nằm trong trình duyệt của bạn (Cài đặt → Lưu trữ để xuất tệp sao lưu).
- Kho này chỉ chứa bản game đã build. Mô hình, âm thanh và nhạc được tạo riêng cho game;
  font Be Vietnam Pro dùng giấy phép SIL Open Font License (`assets/fonts/OFL.txt`).
